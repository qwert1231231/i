Language reference

Learn the core syntax.

These examples match the current project structure and interpreter.

Output

pin, prt, and related output helpers print values.

pin("Hello")
pin("Score:", 100)

Variables

Assignment is intentionally direct and readable.

name = "Ada"
score = 42
score += 8

Conditions

if score >= 50 {
    pin("pass")
} else {
    pin("try again")
}

Loops

for i in items {
    pin(i)
}

for i = 1 to 5 {
    pin(i)
}

loop {
    skip
    break
}

Functions

dec greet(name) {
    pin("Hello", name)
}

greet("world")

Get started

Install I in minutes.

The project currently ships as a Python package with a command-line entry point.

Linux / macOS

git clone https://github.com/qwert1231231/i.git
cd i
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
i examples/hello.i

Windows

git clone https://github.com/qwert1231231/i.git
cd i
py -m pip install -e .
i examples/hello.i

Or run directly with python -m i examples/hello.i.

FAQ

Questions, answered.

What is I?

I is a small, beginner-friendly programming language with a Python-based implementation.

Is I open source?

Yes. The language implementation, examples, and tests live in the public GitHub repository.

Can I contribute?

Yes. Start by exploring the lexer, parser, interpreter, examples, and tests, then open an issue or pull request.

Can this website run the complete interpreter?

The playground is a safe browser-side syntax demo. The authoritative runtime is the Python interpreter in the repository, which you can run locally.
