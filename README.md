# I Language

I is a small, beginner-friendly language inspired by Python, C, Rust, C#, and JavaScript.

## Example

```i
out("Hello, world!")
```

## Install

### Linux / macOS

```bash
python -m pip install -e .
```

### Windows

```powershell
py -m pip install -e .
```

## Run a file

```bash
i hello.i
```

## Run the project directly

```bash
python -m i examples/hello.i
```

## Run tests

```bash
python -m pytest -q
```
